# 02. 커리큘럼 초안 — 15단원 / 10주

단원별 세부 목차(출발선 질문, Δ개념 1·2·3, 예제, 연습 문항, 쪽수)는 `03-syllabus.md`.

2022 개정 교육과정 일반선택 「물리학」의 3개 영역을 15단원으로 나눈 초안.
영역별 세부 내용 요소와 성취기준 번호는 확정 전에 교육과정 원문과 대조가 필요하다.
특히 아래 표시한 항목은 교과서 출판사별 배치가 다를 수 있으니 사용하는 교과서 기준으로 조정한다.

## 단원 구성

| 단원 | 영역 | 제목 | 핵심 내용 | 비고 |
|---|---|---|---|---|
| Δ00 | 준비 | 출발선 | 벡터와 스칼라, 단위, 그래프 읽기(기울기·넓이) | 예비고1용 준비 단원. 첫 주 앞부분에 배치 |
| Δ01 | 힘과 에너지 | 운동의 표현 | 위치·변위·속도·가속도, Δ의 의미, 평균과 순간 | 책 이름과 연결되는 첫 단원 |
| Δ02 | 힘과 에너지 | 등가속도 운동과 그래프 | 등가속도 공식 3개, x–t / v–t / a–t 그래프 해석, 자유 낙하 | |
| Δ03 | 힘과 에너지 | 뉴턴 운동 법칙 | 관성, F=ma, 작용 반작용, 알짜힘 | 내지 샘플 단원 |
| Δ04 | 힘과 에너지 | 운동 법칙의 적용 | 실로 연결된 물체, 도르래, 빗면, 마찰 | 계 나누기 훈련 |
| Δ05 | 힘과 에너지 | 평형과 안정성 | 돌림힘, 힘의 평형·돌림힘의 평형, 무게중심, 구조물의 안정성 | 2022 개정 신설 비중 확인 |
| Δ06 | 힘과 에너지 | 운동량과 충격량 | 운동량, 충격량, 운동량 보존, 충돌 | |
| Δ07 | 힘과 에너지 | 일과 역학적 에너지 | 일, 운동·퍼텐셜 에너지, 역학적 에너지 보존, 비보존력 | |
| Δ08 | 힘과 에너지 | 열과 에너지 | 열역학 제1법칙, 열기관과 효율, 열역학 제2법칙(엔트로피) | 역학 마무리 |
| Δ09 | 전기와 자기 | 전기장과 전위 | 전하와 쿨롱 법칙, 전기장, 전위와 전위차, 축전기 | 축전기 포함 여부 교과서 확인 |
| Δ10 | 전기와 자기 | 전류와 전기 회로 | 전류·저항·옴 법칙, 저항 연결, 전기 에너지와 전력 | |
| Δ11 | 전기와 자기 | 전류의 자기 작용 | 직선·원형·솔레노이드 자기장, 자기력, 자성체 | |
| Δ12 | 전기와 자기 | 전자기 유도와 전자기파 | 패러데이 법칙, 렌츠 법칙, 발전기, 변압기, 전자기파 스펙트럼 | |
| Δ13 | 빛과 물질 | 파동과 빛의 성질 | 파동의 표현, 굴절과 전반사, 간섭·회절 | 광통신 포함 여부 확인 |
| Δ14 | 빛과 물질 | 빛과 물질의 이중성 | 광전 효과, 광자, 물질파, 전자 현미경 | |
| Δ15 | 빛과 물질 | 원자와 에너지 준위 | 보어 원자 모형, 스펙트럼, 에너지띠, 반도체와 다이오드 | 반도체 배치 교과서 확인 |

## 주차 배분 (10주)

| 주차 | 단원 | 비고 |
|---|---|---|
| 1 | Δ00, Δ01 | 출발선 + 운동의 표현 |
| 2 | Δ02, Δ03 | 등가속도 운동, 뉴턴 운동 법칙 |
| 3 | Δ04, Δ05 | 적용 문제, 평형 |
| 4 | Δ06, Δ07 | 운동량, 에너지 |
| 5 | Δ08 + 역학 총정리 | 열 + 힘과 에너지 영역 점검 |
| 6 | Δ09, Δ10 | 전기장, 회로 |
| 7 | Δ11, Δ12 | 자기, 전자기 유도 |
| 8 | Δ13 + 전자기 총정리 | 파동 + 전기와 자기 영역 점검 |
| 9 | Δ14, Δ15 | 이중성, 원자 |
| 10 | 전 범위 총정리 | 모의 평가 + 주간 Δ 마무리 |

## 9주로 줄일 때
5주차 역학 총정리를 4주차 끝에 붙이고, 8주차 전자기 총정리를 7주차 끝에 붙인다.
10주차 전 범위 총정리는 유지한다.

## 확정 전 결정할 것
1. 사용하는 교과서(출판사)와 단원 배치 대조
2. 예비고1을 위한 Δ00 준비 단원 분량 (4쪽 vs 8쪽)
3. 특수 상대성 이론 포함 여부 (2022 개정에서는 진로선택으로 이동한 것으로 알고 있으나 확인 필요)
4. 각 단원 연습 문제 수 (▲ 4 / ▲▲ 4 / ▲▲▲ 2 기본안)
