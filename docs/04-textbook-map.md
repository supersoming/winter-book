## 교과서 순서와 이 책 순서
교과서는 평형(정적) → 뉴턴 법칙·등가속도 → 운동량 순서다. 이 책은 운동의 표현 → 등가속도 → 뉴턴 → 적용 → 평형 → 운동량 순서로, 예비고1이 처음부터 따라올 수 있는 순서를 택했다. 학교 진도와 맞출 필요가 있으면 Δ05를 Δ01 앞으로 당겨 수업해도 단원끼리 의존이 없다.
